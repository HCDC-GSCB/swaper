Trực quan hóa dữ liệu với R

Visualization
R
Trực quan hóa cung cấp cái nhìn tổng quát trong so sánh kết quả. Trực quan hóa là một nghệ thuật
Author

An Tran

Published

July 2, 2025

Trực quan hóa

  • Trực quan hóa nó để truyền bá thông tin.

  • Trong R-based, chúng ta sử dụng plot() để vẽ hình.

  • Trong tidyverse, chúng ta sử dụng gói ggplot2

Ví dụ

Base R:

plot(
  x = mtcars$wt,
  y = mtcars$mpg,
  xlab = "Weight (1000 lbs)",
  ylab = "Miles Per Gallon",
  main = "MPG vs. Weight",
  pch = 19,       # Solid circle points
  col = "blue"
)

ggplot2:

library(ggplot2)
ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point(color = "blue") +
  scale_x_continuous("Weight (1000 lbs)") +
  scale_y_continuous("Miles Per Gallon") +
  ggtitle("MPG vs. Weight") + 
  theme_bw()

Package ggplot2

  • ggplot2 hoạt động trực tiếp với dữ liệu tidy (giống như mọi thứ trong tidyverse).

  • Nó dựa trên một khái niệm gọi là grammar of graphics.

  • Có tài liệu hướng dẫn toàn diện về cách sử dụng.

  • Cung cấp đủ tính linh hoạt để tùy chỉnh.

Cấu trúc của ggplot2

  • Một khuôn khổ để mô tả và xây dựng biểu đồ theo cách có cấu trúc.

  • Phương pháp tiếp cận theo layer, tức là mỗi thành phần của một hình là các layer riêng biệt.

Ví dụ

  • Hãy xem code ví dụ sau:
ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point(color = "blue") +
  scale_x_continuous("Weight (1000 lbs)") +
  scale_y_continuous("Miles Per Gallon") +
  ggtitle("MPG vs. Weight") + 
  theme_bw()
  • Data: mtcars
  • Aesthetics: aes(x = wt, y = mpg)
  • Geometries: geom_point
  • Coordinates: scale_x_continuous, scale_y_continuous
  • Theme: theme_bw, ggtitle
Tip

ggplot2 chỉ chạy với dữ liệu là data frame và không thể chạy với loại dữ liệu khác (ví dụ: ma trận hoặc vectơ).

Aesthetics

  • Phải đặt trong aes().
  • Khai báo thông tin các trục x, y.
  • Khai báo màu sắc color, fill.
df <- data.frame(
  x = 1:10,
  y = (1:10)^2,
  group = rep(c("A", "B"), each = 5)
) 
ggplot(df, aes(x, y, color = group)) + 
  geom_col()
ggplot(df, aes(x, y, fill = group)) + 
  geom_col()

Geometries

  • geom_col or geom_bar: biểu đồ cột/ thanh
  • geom_histogram: histograms
  • geom_point: biểu đồ chấm (scatter)
  • geom_line or geom_smooth: biểu đồ đường (làm mượt)
  • geom_boxplot: biểu đồ hộp
Tip

Data, aesthetic, geometric đối tượng là thành phần quan trọng của biểu đồ, nếu cấu trúc này không đủ thì cốt truyện sẽ không hoạt động.

Shape of geom_point

Coordinates

  • Tùy chỉnh hiển thị của các trục: scale_x_..., scale_y_..., xlim, ylim,…
  • Tùy chỉnh màu sắc theo giá trị của từng biến: scale_color_..., scale_fill_...,…
  • Tùy chỉnh tên cột, tên biểu đồ, tên chú thích: labs

Themes

  • Tùy chỉnh background của biểu đồ: màu sắc, lưới,…
  • Tùy chỉnh kiểu chữ trên biểu đồ.
  • Có sẵn một số theme để lựa chọn: theme_classic, theme_minimal,…

ggplot(df_plot, aes(x = coverage, y = inequality)) +

  geom_text(aes(label = country))

ggplot(df_plot, aes(x = coverage, y = inequality)) +
  geom_point() +
  geom_text(aes(label = country), hjust = -0.2, vjust = 0.2)
  • Tùy chỉnh giá trị hiển thị của trục x, y.

  geom_text(aes(label = country), hjust = -0.2, vjust = 0.2) +
  xlim(c(-0.35, 0.55)) +
  ylim(c(-0.17, 0.1))

set.seed(123)
np <- 50
rd <- data.frame(
  country = rep("", np),
  coverage = rnorm(n = np, mean = 0.1, sd = 0.12),
  inequality = rnorm(n = np, mean = -0.05, sd = 0.04),
  size = rnorm(n = np, mean = 1, sd = 0.4),
  color = sample(
    c("red", "green", "darkblue", "yellow", "blue", "purple"),
    np,
    replace = T
  )
)

  • set.seed(123): dùng để cố định cách tạo ra các điểm ngẫu nhiên.

  • np <- 50: tạo ra 50 điểm ngẫu nhiên.

  • country = rep("", np): các điểm này không có tên quốc gia.

  • coverage = rnorm(n = np, mean = 0.1, sd = 0.12): số thực được tạo ra ngẫu nhiên theo phân phối bình thường với trung bình là 0.1 và độ lệch chuẩn là 0.12.

  • inequality = rnorm(n = np, mean = -0.05, sd = 0.04): số thực được tạo ra ngẫu nhiên theo phân phối bình thường với trung bình là -0.05 và độ lệch chuẩn là 0.04.

  • size = rnorm(n = np, mean = 1, sd = 0.4): số thực được tạo ra ngẫu nhiên theo phân phối bình thường với trung bình là 1 và độ lệch chuẩn là 0.4.

  • color = sample(1:6, np, replace = T): màu sắc là số nguyên ngẫu nhiên từ 1 đến 6.

  • Chúng ta thử ghép 2 bộ dữ liệu.

df_plot <- rbind(df_plot, rd)

  geom_point(aes(size = size, color = color)) +
  geom_text(aes(label = country), hjust = -0.2, vjust = 0.2) +

Bản đồ

  • Trước khi bạn muốn tạo bản đồ, bạn phải có shapefile (định dạng là .shp).

  • Trong ggplot2, bạn có thể sử dụng hàm geom_map để tạo bản đồ.

  • Bạn có thể xem thêm thông tin trong Cheatsheet.

Tip

Nếu sử dụng `ggplot2, chúng ta cần sử dụng tidyverse.
